# PWA UI / UX 修正 QA

## 自動檢查

- 特休設定的畫面單位是小時，讀取與儲存時仍和整數分鐘互相轉換。
- 一般設定表單依「欄位 → 操作 → 說明」排列，操作列共用間距並支援窄螢幕換行。
- 手動假日匯入位於預設收合的「進階：假日資料管理」。
- 還原仍先產生並下載目前資料的安全備份；只有選擇「繼續還原」才會寫入資料庫。
- 日曆進入編輯時保留年、月與捲動位置；成功儲存或取消後返回原月份。

## 人工驗收清單

以下項目需在可操作瀏覽器中執行，不以程式檢查冒充實機驗收：

- [ ] 既有 `14400` 分鐘在設定畫面顯示 `240` 小時；改為 `200` 儲存並重新整理後仍顯示 `200`。
- [ ] 所有儲存按鈕位於說明上方，欄位與操作列有清楚間距，並排按鈕有清楚分界。
- [ ] 在 360px、390px、768px 與桌面寬度檢查表單、按鈕換行、對話框與觸控範圍。
- [ ] 進階假日區預設收合，鍵盤可展開，展開後仍可匯入 JSON。
- [ ] 從非本月的日曆紀錄進入編輯；儲存及取消都返回原月份與接近原捲動位置，且儲存內容立即更新。
- [ ] 選擇有效備份並開始還原；確認先觸發安全備份下載，對話框顯示檔名及「繼續還原／取消還原」。
- [ ] 選擇「取消還原」後確認資料未變；再次操作並選擇「繼續還原」後確認還原成功。
